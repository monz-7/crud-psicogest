## Cómo ejecutar

- Clonar el repositorio.

```
git clone https://github.com/monz-7/crud-psicogest.git
```

- Importar la base de datos en XAMPP

```
http://localhost/phpmyadmin
```

- **Crear una base de datos llamada `crud_psicogest`**
- **Importar archivo [ `database.sql` ]** que crea la tabla **_`patients`_** con su estructura.

- Ejecutar en XAMPP (`http://localhost/crud-psicogest`).
